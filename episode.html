Step 1

Object identification — VLM

A vision-language model watches the episode and names the manipulated object, then judges whether it is suitable for 3D box tracking at all.

Step 1b

Rigidity gate — VLM

Pose tracking assumes a rigid object. A second VLM pass decides whether this object holds its shape under manipulation.

Step 3a-1

Seed masks — SAM3 image mode

SAM3 is run per frame on every camera; the highest-scoring frame in each view becomes that camera's seed. These are single still frames, so they do not move with playback.

Step 3a-1 v2

Propagated mask tracklets — SAM3 video mode

Each camera's seed mask is propagated through the whole clip by the SAM3 video predictor. Where the overlay disappears, the tracker judged the object not visible.

Step 3a-2

Tracked 3D box — reprojected per view

The final world-frame box from FoundationPose, projected back into each camera. The wrist camera reprojects through its per-frame pose; the two externals use the optimized static extrinsics. Where no box is drawn, the tracker had no reliable pose for that frame.
